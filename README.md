# 体素星球 · 知识探险

Three.js 本地原型。星球的线性半径从 26 增加到 260，地形、海岸、植被和角色改为方块风格。海洋与陆地属于同一套体素球面网格。

## 知识探险（小学五、六年级）

右上角点击“知识探险”，选择五或六年级的英语、数学、语文题库。内置题库共 60 道题，每个年级和学科组合 10 道，按入门、练习、挑战分配给三座遗迹。左侧任务卡显示下一座遗迹的方向和距离。靠近发光遗迹后按 `E`、点击“进入遗迹”，或在体感模式下握拳进入。选择题点选答案；配对题先点左侧，再点右侧。答错会显示解析并允许重试；完成一座遗迹可恢复 15 点生命，完成三座后点亮复活点附近的灯塔。答题时暂停移动和战斗。各课程的答题进度保存在当前浏览器的本地存储中。

可以在“知识探险”里下载当前完整题库的 JSON 文件，修改后再导入自己的题目。JSON 顶层是题目数组；每道题需要唯一 `id`、`grade`（5 或 6）、`subject`（`english`、`math`、`chinese`）、`difficulty`（`easy`、`medium`、`hard`）、`type`、`prompt` 和 `explanation`。四选一题使用 `type: "choice"`、四个字符串组成的 `options` 和从 0 开始的 `answer` 索引。配对题使用 `type: "pair"` 和三组 `[左侧, 右侧]` 组成的 `pairs`。同一年级、同一学科至少有 3 道题才会成为可玩课程；导入新题库会重置自定义题库进度，内置题库进度保留。导入文件仅在本地读取。可在面板里重置当前课程，以重新挑战。

## 运行

Windows：双击 [启动游戏.cmd](./启动游戏.cmd)。首次启动会自动安装依赖，随后打开浏览器。保持启动窗口打开；按 `Ctrl+C` 停止服务。不要直接双击 `index.html`，因为浏览器会阻止 `file://` 页面加载 ES 模块和区块 Worker。

macOS：双击 [启动游戏.command](./启动游戏.command)。首次启动会自动安装依赖，随后打开浏览器。保持终端窗口打开；按 `Ctrl+C` 停止服务。

也可使用命令行：

```bash
npm install
npm run dev
```

打开终端显示的本地地址。使用 `npm run build` 检查生产构建。

## 操作模式与默认值

关卡右上角可随时切换“电脑”和“体感”。当前默认是**电脑操作**，不请求摄像头。要修改全局默认值，请编辑 `src/input-config.js` 中的 `DEFAULT_INPUT_MODE`，可设为 `'computer'` 或 `'motion'`。打开地址时也可用 `?input=motion` 或 `?input=computer` 临时覆盖本次启动模式。切回电脑操作会关闭摄像头与识别线程。

### 电脑操作

`W/A/S/D` 或方向键移动，按住 `Shift` 奔跑；拖动鼠标旋转视角，滚轮缩放到整颗星球。按 `B` 开关背包、`E` 拾取或找回、`Q` 使用浆果、`H` 隐藏部分界面。也可点击界面按钮操作。

## 体感操作

切换到“体感”后，点击“开启摄像头”并允许浏览器访问摄像头。让头部、手和双脚都处于画面中，站稳完成校准。识别模型和视频都在本机处理；关闭摄像头后立即停止识别。摄像头需要 `localhost` / `127.0.0.1` 或 HTTPS 页面，不能直接打开 `index.html`。

- 原地交替踏步让角色行走；加快步频并抬高双腿后奔跑。停止踏步即停下。左右侧倾转向；踏步时身体明显后倾可后退。
- 举起右手并移动手掌旋转镜头。双手在胸腹前张开或靠拢调整缩放；也可用场景校准面板的视角按钮直接看整颗星球。
- 举起左手约 0.7 秒打开或关闭背包。右手食指控制光标，拇指和食指捏合选择按钮、装备和道具；在滑杆上保持捏合并移动可调整数值。
- 靠近地面物品或遗物后右手握拳拾取。右手食指靠近嘴部可使用浆果治疗；敌人仍会自动追击，角色自动攻击。首次进入关卡时复活点附近有一把石剑。
- 生命归零时回到初始复活点。装备和背包物品会留在死亡地点，可跟随左上角遗物方向与距离提示找回。
- 体感光标可以操作右侧场景校准、参考图对照和保存截图。浏览器摄像头授权及系统文件选择窗口仍由浏览器或操作系统处理。

右下角预览会显示“停止 / 行走 / 奔跑”识别状态，可在此重新校准或关闭摄像头。识别不到全身、切到其他标签页或关闭摄像头时角色会停止移动。

## 区块渲染

- 整球使用每个立方体面 48×48 单元的低细节网格，保证缩小后仍有完整体素星球。
- 近景采用每个面 512×512 单元的精细网格，按 16×16 单元分块。地形、方块树、矮草和花朵合并进每个区块的网格。
- 仅生成可见表面与邻居低于当前方块时暴露的侧面；隐藏面不进入网格。
- Web Worker 在后台生成近景区块，主线程仅接收顶点数据并上传 GPU。区块按与镜头、角色的距离排序加载。
- 活动区块数量设有上限；远离镜头或切换到整球视角时，从场景移除区块并释放 GPU 几何内存。Three.js 还对各区块执行视锥裁剪。
- 角色贴地采样与区块网格使用同一格点规则，避免镜头移动时落入地表。

## 战斗、背包与掉落

- `src/items.js` 是道具目录，定义类型、描述、属性、消耗效果、稀有度与堆叠上限。`src/inventory.js` 管理 24 格容量、堆叠、装备交换、使用与丢弃；`src/inventory-ui.js` 渲染可操作的背包界面。
- `src/game-rules.js` 定义玩家与敌人数值、伤害、死亡掉落和找回规则。增加敌人类型时从这里扩展。
- `src/enemy-system.js` 在球面上用带少量随机扰动的均匀采样生成固定刷新点，只实例化玩家附近的敌人。敌人有警戒、追击、脱战、攻击与死亡后延迟重生状态；整球/近景观察时暂停战斗。
- 敌人死亡时把星晶留在地面；`src/item-world.js` 管理地面物品的可见性与拾取距离。`src/loot-system.js` 管理死亡遗物，多个遗物可同时保留。背包已满时，未取回的物品会继续留在原地。
- `src/save-game.js` 将玩家、背包、装备、位置、地面物品和遗物写入浏览器本地存储，并兼容旧版存档。存储只属于当前浏览器和当前站点地址。
- `src/motion-worker.js` 在独立线程运行本地 MediaPipe 姿态与手部模型；`src/motion-gestures.js` 负责走跑、转向、手势与误触抑制；`src/motion-control.js` 负责摄像头生命周期、手势光标及界面操作。

体感模型保存在 `public/models/`，分别来自 [Google Pose Landmarker Lite](https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task) 和 [Google Hand Landmarker](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task)。运行所需 WASM 文件来自已安装的 `@mediapipe/tasks-vision` 软件包。首次加载约需下载 27 MB 的本地模型与 WASM 文件，之后由浏览器缓存。

使用 `npm test` 运行刷新点、自动战斗、背包操作、死亡掉落与重载找回检查。当前尚未包含方块编辑、合成或跨区块的可破坏地形。
