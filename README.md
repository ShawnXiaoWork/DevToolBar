# Antigravity Economy Designer 💎

> **专业级游戏经济数值工作台** - 基于金本位体系与玩家模型的实时推演工具。

这是一个为数值策划设计的集成化开发环境（IDE），旨在解决游戏经济设计中产消脱节、资源价值混乱以及长线趋势难以把控的痛点。

---

## 🚀 核心设计哲学：金本位流水线

本工具将经济设计抽象为一套严密的“生产流水线”，确保每一项数值变动都有据可依：

1.  **资源基石 (Dictionary)**: 建立以钻石（或其他基准货币）为核心的汇率体系，统一价值度量衡。
2.  **玩家模型 (Player Model)**: 定义玩家的真实“体感”。包括在线时长、活跃效率以及不同生命周期的成长目标（战力缺口）。
3.  **产耗配置 (Feature Config)**: 为每个功能模块注入实时推演引擎。在配置收益的同时，直接观察其对玩家 Day 7/Day 30 经济的影响。
4.  **全局审计 (Validation)**: 静态审计仪表盘。汇总全模块产消，通过“红绿灯”系统自动识别通胀风险或产出不足。

---

## ✨ 关键特性

### 💎 金本位定价与换算助手
*   **规则化定价**: 通过定义“道具类型基准价值”与“品质系数”，一键拉平海量道具价值。
*   **反向数量换算**: 在功能卡片中选择“材料+蓝色”，系统自动将钻石价值反向推导为道具数量，告别手动计算器。

### 📊 实时推演引擎 (Live Audit)
*   **动态 ROI 分析**: 配置每分钟产出时，实时计算第 7 天的累计收益价值。
*   **目标关联**: 消耗系统直接与 `PlayerModel` 中的“目标战力缺口”关联，自动换算维持进度所需的投入。

### 🚦 静态审计与红绿灯预警
*   **结余曲线**: 直观展示 1/3/7/30 天的资源盈余趋势。
*   **风险警告**: 
    *   🔴 **资源溢出**: 产出远超目标缺口，可能导致系统贬值。
    *   🟡 **解锁冗余**: 功能解锁太早但产出贡献极低。
    *   🟢 **健康平衡**: 产消比在合理阈值内。

### 📥 Excel 工业化集成
*   **双向同步**: 支持资源字典与功能配置的 Excel 批量导入/导出。
*   **智能容错**: 导入过程中自动校验资源 ID 关联性，防止死链接。

## 🏁 快速开始

1.  **安装依赖**:
    ```bash
    npm install
    ```

2.  **启动开发环境**:
    ```bash
    npm run dev
    ```

3.  **设计路径建议**:
    *   先去 **Dictionary** 页设定资源汇率。
    *   在 **Player Model** 设定玩家每天玩多久、想要多快变强。
    *   到 **Feature Config** 填入具体的收益和消耗系数。
    *   最后在 **Validation** 观察全局曲线是否平滑。
